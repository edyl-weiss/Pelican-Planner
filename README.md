# Pelican Planner

A Stardew Valley 1.6 planning companion!

## Included features

- Season-aware visual theme, handwritten body font and pixel headings.
- Daily priorities driven by weather, current date, goals and reserved resources.
- Seasonal calendar with festivals, birthdays, pinned tasks and recorded harvests.
- All 30 standard Community Center bundles.
- Sixteen crop comparisons with harvest timing and explicit assumptions.
- Crop planting, watering delays and harvest recording.
- Inventory tracking, purchase comparisons and resource reservations.
- Sixteen common seasonal bundle fish.
- Basic Stardew XML save import, journal JSON export/import and previous-save recovery.

## English / 简体中文 and interaction effects

Use the language switch in the header or More screen. The first visit follows the browser language; your choice is remembered on this device. All four screens, planner recommendations, calendar labels, dialogs, validation messages and accessible labels support Simplified Chinese. Chinese game terminology follows the official Chinese Stardew Valley Wiki; the planner’s original explanatory text is translated specifically for this project. Wiki links follow the selected language. Collection search accepts either English or Chinese.
