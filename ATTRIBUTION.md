# Asset attribution

## Stardew Valley

Stardew Valley game artwork and sprites © ConcernedApe. All included game sprites were retrieved from canonical Stardew Valley Wiki image URLs. The app is an unofficial fan companion, not an official product.

`lib/game/assets-source.json` records the observed source page, original image URL, native dimensions, retrieval date and attribution for each asset. It is not a claim that the game artwork has the same license as the Wiki's textual contributions.

Primary gameplay references:

- https://stardewvalleywiki.com/Crops
- https://stardewvalleywiki.com/Bundles
- https://stardewvalleywiki.com/Calendar
